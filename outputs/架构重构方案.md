# EduAgent 架构重构方案

## 一、现状问题

1. **后端有两套调度系统**：OpenClaw（真正在跑）和 Python AgentOrchestrator（引用已删除 Agent，崩溃）
2. **product.py 4400 行**，三成是死代码，两成是重复逻辑
3. **数据流不统一**：OpenClaw 结果存 conversation_store → agent_proxy 读缓存 → 前端页面读 → 格式不对全丢
4. **Agent shim 目录**只剩空壳 + pycache 垃圾

## 二、重构目标

**后端瘦身到原来的 1/3——纯 HTTP 代理 + 数据适配。OpenClaw 是唯一调度引擎。前端不变。**

## 三、删除清单

```
backend/app/agents/              整个目录（空壳 + pycache）
backend/app/services/orchestrator.py   死代码
backend/app/services/agent_service.py 的 run_agents() 函数（其他函数保留）
backend/app/routers/agents.py         已废弃
backend/app/mock/                     已废弃
backend/app/schemas/agent.py          已废弃
backend/tests/                        全导入已删除模块
frontend/src/api/knowledge.ts         与 learningPath.ts 重复
frontend/src/api/timeline.ts          与 feedback.ts 重复
```

  ├─ routers/auth.py          — 不变

  ├─ routers/learner.py       — 不变  
  ├─ routers/history.py       — 不变

  ▼

## 五、数据流（重构后）

```
学生说"帮我规划两周的神经网络学习路径"
  │
  ▼
product.py POST /api/chat/stream
  │
  ├─ 1. _classify_intent → intent=plan → 秒回 "好的，正在处理～"
  │
  ├─ 2. openclaw_bridge.process_message_stream() → OpenClaw SSE
  │      │
  │      ├─ Socratic Profiler   → 画像
  │      └─ DeepTutor chat      → 路径 + 资源（一步到位）
  │
  ├─ 3. 流式 SSE 事件 → 前端进度条
  │
  ├─ 4. OpenClaw 最终事件含全部结果 → _persist_results() → conversation_store
  │
  └─ 5. 前端画像/路径/资源页面 → GET endpoint → agent_proxy → conversation_store → 直接返回
```

## 六、实施步骤

### 步骤 1：删除死代码（10 分钟）
```
rm -rf backend/app/agents/
rm backend/app/services/orchestrator.py
rm backend/app/routers/agents.py
rm -rf backend/app/mock/
rm backend/app/schemas/agent.py
rm -rf backend/tests/
```

### 步骤 2：重写 product.py 核心路由（30 分钟）
- 删掉 `_run_agents()`、`_reply_for_intent()`、`_generate_final_reply()` 等死函数
- `_classify_intent` 只判意图不调 Agent
- 流式 handler 走 OpenClaw
- GET 端点走 agent_proxy

### 步骤 3：统一 agent_proxy 为唯一数据读取层（20 分钟）
- 画像 → Socratic Profiler
- 路径/资源/试题 → conversation_store（OpenClaw 缓存）
- 分析 → GRADE

### 步骤 4：修 agent_service.py（10 分钟）
- 删 `run_agents()`
- 保留 `get_profile()`、`get_learning_path()`、`get_resources()`、`get_analytics()`——它们读 DB 作为兜底

### 步骤 5：验证 + 测试（20 分钟）
- 启动全部 6 服务
- 完整跑通：对话→画像→路径→资源→批改
