## 第一章 设计总纲与全局框架

### 1.1 产品定位

一款基于多智能体架构的对话式个性化学习系统。学生通过自然语言与系统交互，系统自动构建学习画像、生成个性化资源、规划学习路径、提供智能答疑、评估学习效果。

### 1.2 核心设计理念

1. **对话即界面**：自然语言是最高优先级的交互方式，GUI 是对话的延伸和可视化呈现
2. **渐进式展示**：资源按需分批生成，不一次性堆砌
3. **智能体透明化**：学生能感知多智能体协同的工作状态
4. **全操作可追溯**：所有系统行为有来源、有解释、可纠错

### 1.3 屏幕适配策略

| 断点 | 布局 |
|:---|:---|
| ≥1440px | 标准三栏：左侧导航(240px) + 中间内容区(flex) + 右侧对话区(400px) |
| 1024-1439px | 两栏：左侧导航(64px图标模式) + 右侧(内容区与对话区上下分屏) |
| <1024px | 单栏层叠式：底部Tab导航，内容区全屏，对话通过FAB浮层唤起 |

### 4.2 生成机制总体原则

**核心原则：资源不一次性全部生成，而是根据学生需求的颗粒度，逐层唤醒不同智能体，分批生成。**

#### 4.2.1 大粒度请求（如"帮我学会操作系统第3章"）

系统行为：
1. 主智能体（协调者）首先介入
2. 生成【资源清单预览】，而非直接生成全部内容
3. 学生确认或调整后，再按优先级分批生成
4. 首批生成核心讲解文档，其他资源排队

#### 4.2.2 中粒度请求（如"讲解进程调度算法"）

系统行为：
1. 直接生成核心讲解文档
2. 文档生成完毕后，底部自动出现相关资源推荐卡片
3. 学生按需点击展开

#### 4.2.3 小粒度请求（如"给这道题出个类似题"）

系统行为：
1. 单一智能体直接生成
2. 即时返回结果

### 4.3 资源生成唤醒机制汇总

| 唤醒方式 | 适用资源类型 | 交互组件位置 | 触发动作 |

## 第十章 异常状态与边界情况

### 10.1 网络异常

| 场景 | 表现 | 处理 |
|:---|:---|:---|
| 请求发送时断网 | 输入框恢复可编辑，消息列表显示发送失败 | 消息气泡右侧红色感叹号，点击重发 |
| 流式输出中断网 | 已输出的文字保留，末尾显示"..." | 自动重连后继续输出；超时则显示[重新生成] |
| 资源生成中断网 | 进度条暂停，显示"网络连接中断" | 恢复后询问"是否继续生成"，支持断点续传 |
| 全站离线 | 顶部出现黄色横幅"当前处于离线状态" | 缓存内容可查看，新请求排队等待恢复 |

### 10.2 生成失败

| 场景 | 表现 | 处理 |
|:---|:---|:---|
| 内容不合规被拦截 | 显示拦截提示卡片 | 建议修改请求措辞 |
| 模型返回超时 | 加载状态持续>60秒 | 自动降级+提示+提供重试 |
| 生成内容格式异常 | Markdown渲染异常 | 提供"查看原始文本"备选+反馈入口 |
| 资源配额用完 | 弹窗提示 | 显示剩余配额+升级方案+降级选项 |

### 10.3 空状态处理

| 场景 | 空状态设计 |
|:---|:---|
| 首次登录无画像 | 引导对话自动开始，头像光环显示0% |
| 无学习路径 | 学习路径页显示引导创建按钮+示例路径模板 |
| 无学习记录 | 学习报告页显示"开始你的第一段学习吧"+快捷入口 |
| 对话记录为空 | 显示欢迎消息+快速开始卡片 |
| 搜索无结果 | 显示"未找到相关内容"+相关推荐 |

### 10.4 边界情况

| 场景 | 处理 |
|:---|:---|
| 对话消息超过500条 | 自动总结前200条为"历史对话摘要"，保留最近300条 |
| 单次上传文件过大(>50MB) | 提示文件大小限制，建议压缩或分段上传 |
| 同时触发多个资源生成 | 排队处理，显示队列顺序，支持调整优先级 |
| 午夜跨天学习 | 学习记录自动归入实际日期，不影响统计 |
| 多设备同时登录 | 后登录设备顶替前设备，前设备弹出"已在其他设备登录" |
| 浏览器兼容性 | 支持Chrome/Firefox/Safari/Edge最近2个主版本，IE不支持时显示升级提示 |

### 10.5 无障碍设计

| 项目 | 规范 |
|:---|:---|
| 色彩对比度 | 文字与背景对比度≥4.5:1(WCAG AA) |
| 键盘导航 | Tab键可在所有可交互元素间切换，Enter激活，Esc关闭弹窗 |
| 屏幕阅读器 | 关键元素有aria-label，动态内容有aria-live |
| 焦点指示器 | 所有可交互元素有清晰的焦点环(2px蓝色轮廓) |
| 文字缩放 | 支持浏览器缩放至200%不破坏布局 |
