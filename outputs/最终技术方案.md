# EduAgent 最终技术方案

## 一、方案概述

**不写一行 Agent 代码。** 全部使用现成开源智能体，只做配置 + 胶水层 + 前端展示页面。

| 来源 | 用途 | 协议 |
|------|------|------|
| **DeepTutor**（港大，20k+ Star） | 多智能体主引擎，6 个 Agent + RAG + 记忆系统 | Apache 2.0 |
| **Socratic Education System**（MIT 开源） | Profiler Agent，对话后自动构建结构化学生画像 | MIT |
| **GRADE**（BEA 2025 Shared Task） | 4 维自动批改 + 错误分级，学术论文验证 | 开源 |
| **OpenMAIC**（清华，MIT） | PPT 课件 + TTS 讲课 + 动画分镜生成 | MIT |
| **讯飞星火 Spark 4.0** | 底层大模型 | 科大讯飞 |
| **讯飞 SeeDance** | 多模态视频生成 | 科大讯飞 |
| **讯飞开放平台** | TTS/ASR/OCR | 科大讯飞 |

**完全满足比赛五大核心要求 + 四条非功能性需求 + 科大讯飞工具要求。**

## 二、多智能体架构

### 2.1 Agent 清单（共 8 个 Agent + 1 个引擎）

| Agent | 来源 | 角色 | 独立人格（System Prompt 定位） |
|-------|------|------|------|
| **InvestigateAgent** | DeepTutor | 意图分析专家 | "你是学习行为分析师，从学生描述中提取知识背景、学习目标、薄弱点" |
| **NoteAgent** | DeepTutor | 结构化记录专家 | "你是学习档案管理员，将分析结果整理为结构化摘要和证据链" |
| **Profiler Agent** | Socratic ES | 学生画像专家 | "你是教育心理学家，从对话记录中提取认知特征，构建多维学习者画像" |
| **PlanAgent** | DeepTutor | 路径规划专家 | "你是课程设计师，根据画像和诊断结果规划分阶段学习路径" |
| **ManagerAgent** | DeepTutor | 资源调度专家 | "你是教学资源管理师，按路径阶段调度对应资源生成引擎" |
| **SolveAgent** | DeepTutor | 智能辅导专家 | "你是一对一辅导老师，基于 RAG 知识库为学生提供即时、精准的答疑" |
| **CheckAgent** | DeepTutor | 质量审核专家 | "你是学术审核员，验证所有生成内容的准确性、安全性和难度匹配" |
| **Grading Agent** | GRADE | 批改评估专家 | "你是试卷批改专家，按多维评分标准对作答进行结构化评估和错误分类" |
| **OpenMAIC 引擎** | OpenMAIC | 多模态课件引擎 | PPT/Slides 生成 + TTS 语音授课 + 动画分镜 |

### 2.3 Agent 间互审机制（防幻觉核心）

```
CheckAgent 审查规则：

┌──────────────────────────────────────────────────────┐
│ 1. 跨 Agent 一致性检查                                │
│    InvestigateAgent 识别的薄弱点                      │
│    ↔ PlanAgent 生成的路径是否覆盖这些点？              │
│    ↔ ManagerAgent 调度的资源是否对症？                │
│                                                      │
│ 2. 内容扎实性检查                                    │
│    每份讲义/题目/推荐材料                              │
│    → Memory Graph 追溯到原始知识库来源                 │
│    → 无来源 → 标记 "当前资料不足，建议人工确认"        │
│                                                      │
│ 3. 安全红线检查                                      │
│    · 无作弊/代写/泄题内容                             │
│    · 无敏感违规信息                                   │
│    · 难度与学生画像匹配                                │
│                                                      │
│ 4. 驳回与重生成                                      │
│    blocked → 打回 ManagerAgent 重新调度               │
│    warning → 标记但放行，前端显示置信度                │
│    passed → 正常输出                                 │
└──────────────────────────────────────────────────────┘
```

## 三、比赛五大要求逐条应对

### 3.1 要求 1：对话式学习画像自主构建（6+ 维）

**负责 Agent**：InvestigateAgent → NoteAgent → Socratic Profiler Agent

**画像维度**：

| 维度 | 字段 | 来源 | 示例值 |
|------|------|------|--------|
| 专业背景 | `major_background` | InvestigateAgent 提取 | "电子信息专业大二，学过数据结构" |
| 知识基础 | `knowledge_base` | InvestigateAgent + GRADE 反馈 | "Python 熟练，机器学习薄弱，概率统计一般" |
| 学习目标 | `learning_goal` | InvestigateAgent 提取 | "两周入门神经网络和 NLP，能做一个小项目" |
| 认知风格 | `cognitive_style` | Socratic Profiler 推断 | "偏好图解、代码案例、互动练习" |
| 易错点 | `error_patterns` | GRADE 批改结果反馈 | "混淆监督/无监督学习，过拟合概念不清" |
| 学习进度 | `learning_progress` | PlanAgent 进度数据 | "已完成神经网络基础，正在学习反向传播" |

**"随学随新"闭环**：
```
学生做练习 → GRADE 批改 → 识别薄弱点 → Socratic Profiler 更新画像
→ PlanAgent 读取新画像 → 调整后续路径 → ManagerAgent 推送补充资源
```

**答辩话术**：
> "画像构建采用三 Agent 协同：InvestigateAgent 从对话中提取原始特征，NoteAgent 生成结构化摘要，Socratic Education System 的 Profiler Agent 将其建模为 6 维画像 JSON。批改评估结果通过闭环反馈自动更新易错点和知识基础字段，实现真正的'随学随新'。"

---

### 3.2 要求 2：多智能体协同资源生成（5+ 类资源）

**负责 Agent**：PlanAgent → ManagerAgent → DeepTutor（Quiz/Deep Research/Visualize） → OpenMAIC → CheckAgent

**6 类资源 + 负责方**：

| # | 资源类型 | 负责 Agent/引擎 | 技术实现 |
|---|---------|----------------|---------|
| 1 | **课程讲解文档** | DeepTutor Deep Research 模式 | RAG（GraphRAG + LightRAG）生成，每条引用标注来源 |
| 2 | **知识点思维导图** | DeepTutor Visualize 模式 | Mermaid 语法生成，前端实时渲染 |
| 3 | **练习题** | DeepTutor Quiz 模式 | 5 种题型（选择/填空/判断/解答/变式），Bloom 分类学对齐 |
| 4 | **拓展阅读材料** | DeepTutor Deep Research 模式 | 网页检索 + 论文检索 + 推荐理由 + 难度标注 |
| 5 | **多模态视频/PPT** | OpenMAIC 引擎 | TTS 语音授课 + PPTX 导出 + 动画分镜脚本 |
| 6 | **代码实操案例** | DeepTutor Deep Solve 模式 | Python 可运行代码 + 分步实验 + 输出验证 |

**防幻觉机制（三层）**：
```
第一层：ManagerAgent 调度时传入知识库上下文，限制生成范围
第二层：CheckAgent 逐条审查，Memory Graph 溯源码引用
第三层：不确定性提示——知识库无覆盖时明确告知"当前资料不足"
```

**答辩话术**：
> "系统设计了 8 个角色化 Agent 协同工作机制。InvestigateAgent 分析需求、PlanAgent 规划路径、ManagerAgent 调度生成引擎、CheckAgent 执行质量审核，形成'分析—规划—生成—审核'的完整闭环。资源生成覆盖讲义、导图、题库、阅读、视频、代码 6 种类型，所有内容经 Memory Graph 证据溯源，确保学术准确性。"

### 3.3 要求 3：个性化学习路径规划和资源推送

**负责 Agent**：PlanAgent + ManagerAgent

**路径规划策略**：
```
PlanAgent 输入：画像 JSON + 诊断结果 + 时间约束
    │
    ├── 阶段拆分：按知识依赖关系 BFS 排序
    ├── 时间分配：按画像学习节奏 × 阶段难度
    ├── 难度适配：画像知识基础 → 匹配起始难度
    └── 风格适配：画像认知风格 → 决定资源类型配比

示例输出：
  阶段1（第1-3天）：机器学习基础概念 + 数学回顾
  阶段2（第4-7天）：监督学习核心算法 + 代码实操
  阶段3（第8-10天）：神经网络与反向传播（图解优先）
  阶段4（第11-13天）：NLP 基础 + 项目实践
  阶段5（第14天）：综合复习 + 模拟测试
```

**资源推送策略**：
```
ManagerAgent 根据画像维度匹配：

认知风格 = "图解"    → 思维导图 + 视频比例 ↑
认知风格 = "代码"    → 实操案例 + 练习比例 ↑
认知风格 = "讲义"    → 课程文档 + 阅读比例 ↑

易错点 = "过拟合"    → 推送过拟合专题讲解 + 变式题
知识基础 = "薄弱"    → 推送前置知识补充资源
```

**动态调整闭环**：
```
GRADE 批改 → Profiler 画像更新 → PlanAgent 重规划 → ManagerAgent 重新推送
```

### 3.4 要求 4：智能辅导（加分项）

**负责 Agent**：SolveAgent（DeepTutor）+ OpenMAIC TTS

**四种答疑形式**：

| 形式 | 实现 | 场景举例 |
|------|------|---------|
| **文字解答** | SolveAgent + 讯飞星火 + RAG 知识库，带引用标注 | "反向传播中的链式法则具体怎么用？" |
| **图解说明** | DeepTutor Visualize 模式，生成 Mermaid 概念图 | "CNN 和 RNN 的结构区别" |
| **短视频讲解** | OpenMAIC TTS 讲课 + 动画分镜 | "梯度下降的直观理解，3 分钟视频" |
| **启发式追问** | SolveAgent 配置为苏格拉底模式 | 学生卡住时不直接给答案，引导自主推导 |

**答辩话术**：
> "智能辅导由 SolveAgent 统一承接，根据问题类型自动切换四种解答形式。概念问题优先推送图解和短视频，计算问题给出分步推导，学生持续卡住时切换为苏格拉底追问模式，引导自主思考而非直接给答案。"

---

### 3.5 要求 5：学习效果评估（加分项）

**负责 Agent**：GRADE Grading Agent

**4 维评分体系**：

| 评估维度 | 权重 | 评分依据 |
|----------|:---:|---------|
| 思路正确性 | 40% | 解题思路是否合理，核心概念是否理解正确 |
| 步骤完整性 | 30% | 推导过程是否完整，关键步骤是否遗漏 |
| 计算准确性 | 20% | 数值计算、公式引用是否正确 |
| 表达规范性 | 10% | 书写格式、符号使用、逻辑表达是否清晰 |

**5 类错误归类 + 自动动作**：

| 错误类型 | GRADE 判断依据 | 系统自动动作 |
|----------|---------------|-------------|
| 概念错误 | 用错公式/混淆概念 | → 推送基础概念讲解 + 区分对比材料 |
| 计算失误 | 过程对但结果错 | → 标注验算步骤 + 同类计算练习 |
| 审题偏差 | 答非所问/漏关键条件 | → 提示关键词标注训练 |
| 方法不当 | 解法可行但非最优 | → 推荐更优解法 + 效率对比 |
| 知识遗忘 | 前置概念空白 | → 加入间隔重复复习队列 |

**评估→画像→规划闭环**：
```
GRADE 评估报告
    │
    ├──→ Profiler Agent 更新 "易错点" 和 "知识基础"
    │        │
    │        └──→ PlanAgent 读取新画像 → 调整路径（弱项加时/强项加速）
    │
    └──→ ManagerAgent 推送针对性补充资源
```

## 四、非功能性需求应对

### 4.1 界面设计

**前端方案**：基于 DeepTutor 自带 Next.js + React 19 前端，**增加 3 个页面 + 2 个组件**。

**页面结构**：

| 页面 | 路由 | 来源 | 说明 |
|------|------|------|------|
| 首页/对话页 | `/chat` | DeepTutor 自带 | 流式对话 + Markdown + 数学公式渲染 |
| **学生画像页** | `/profile` | **新增** | 6 维画像卡片 + 雷达图 + 历史变化趋势 |
| 学习路径页 | `/path` | DeepTutor 自带（改造） | 阶段卡片 + 进度条 + 甘特图时间线 |
| 资源库 | `/resources` | DeepTutor 自带（改造） | 多模态卡片（讲义/导图/视频/题目/代码） |
| **批改结果页** | `/grading` | **新增** | 4 维评分雷达图 + 错误分类标签 + 改进建议卡片 |
| 学习分析页 | `/analytics` | **新增** | 掌握度热力图 + 学习时长 + 正确率趋势 |

**关键交互**：流式输出 / Markdown 渲染 / KaTeX 数学公式 / 进度条追踪 / 骨架屏加载态 / 响应式布局。

| 机制 | 实现 |
|------|------|
| **第一层** | ManagerAgent 传入知识库上下文，限制 LLM 生成边界 |
| **第二层** | CheckAgent 逐条审核，Memory Graph 追溯每条引用的知识库来源 |
| **第三层** | 无来源标注 → 前端显示 "⚠ 当前资料不足，以下内容仅供参考" |

| 场景 | 策略 |
|------|------|

| **路径规划** | 同步返回阶段概览 → 异步展开每日任务 |
| **资源生成** | 分批生成 + 实时进度流 + 卡片逐个浮现 |
| **多模态资源** | 提交生成任务 → 轮询进度 → 完成后通知 + 预览 |
| **批改** | 选择题即时判分，解答题 SSE 流式输出评分过程 |
