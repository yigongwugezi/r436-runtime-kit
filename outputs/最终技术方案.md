# EduAgent 最终技术方案

## 一、方案概述

基于开源项目 **DeepTutor**（港大，Apache 2.0）作为多智能体主引擎，**OpenMAIC**（清华，MIT）补齐多模态资源生成，底层大模型全面接入科大讯飞系列产品。

- 你需要写的代码：约 500 行
- 现成可用的 Agent：6 个（DeepTutor 自带）+ OpenMAIC 课件引擎
- 完全满足比赛五大要求和所有非功能性需求

---

## 二、多智能体架构

### Agent 清单

| Agent | 来源 | 角色 | 负责的比赛要求 |
|-------|------|------|:---:|
| InvestigateAgent | DeepTutor 自带 | 分析学生输入，提取知识背景、目标、薄弱点 | 要求1 |
| NoteAgent | DeepTutor 自带 | 结构化记录，生成学习摘要和证据链 | 要求1 |
| **ProfileAgent** | **你写** | 构建 6+ 维动态学生画像，随学随新 | 要求1 |
| PlanAgent | DeepTutor 自带 | 生成个性化学习路径，分阶段规划 | 要求3 |
| ManagerAgent | DeepTutor 自带 | 资源调度，按路径阶段调取对应生成能力 | 要求2,3 |
| SolveAgent | DeepTutor 自带 | 智能辅导，多模态答疑 | 要求4 |
| CheckAgent | DeepTutor 自带 | 验证答案、防幻觉、内容安全审核 | 要求2(互审) |
| **GradingAgent** | **你写** | 多维评分 + 错误归类 + 学习效果评估 | 要求5 |
| OpenMAIC 引擎 | OpenMAIC | PPT/视频/动画/TTS 讲课 | 要求2 |

### 协作流程

```
学生输入 "我是电子信息大二，想学机器学习，基础薄弱"
    │
    ▼
InvestigateAgent + NoteAgent        → 分析意图、提取关键信息
    │
    ▼
ProfileAgent (你写)                  → 构建 6 维画像 JSON
    │
    ▼
PlanAgent                            → 生成分阶段学习路径
    │
    ▼
ManagerAgent                         → 调度资源生成
    ├──→ DeepTutor Quiz 模式         → 练习题
    ├──→ DeepTutor Deep Research     → 拓展阅读
    ├──→ OpenMAIC                    → PPT + TTS 讲课 + 动画
    └──→ DeepTutor Math Animator     → 公式推导动画
    │
    ▼
CheckAgent                           → 审查所有资源（防幻觉 + 安全过滤）
    │
    ▼
SolveAgent                           → 即时答疑
    │
    ▼
GradingAgent (你写)                  → 批改 + 评估 → 反馈给 ProfileAgent "随学随新"
```

## 三、比赛五大要求应对

### 要求 1：对话式学习画像自主构建（6+ 维）

**方案**：InvestigateAgent + NoteAgent 提取原始信息 → ProfileAgent（你写）结构化输出

画像维度：

| 维度 | 说明 |
|------|------|
| 专业背景 | 专业、年级、相关课程经历 |
| 知识基础 | 先修知识掌握程度 |
| 学习目标 | 短期/长期目标 |
| 认知风格 | 偏好学习方式（图解/代码/讲义） |
| 易错点 | 常见错误类型和薄弱环节 |
| 学习进度 | 当前课程学习位置 |

"随学随新"：GradingAgent 批改结果 → 反馈给 ProfileAgent → 自动更新画像字段

**答辩话术**："通过 InvestigateAgent 和 NoteAgent 双 Agent 分析环提取学生特征，再经 ProfileAgent 构建 6 维结构化画像，批改评估结果通过 Memory Graph 自动回溯更新画像字段，实现真正的随学随新。"

---

### 要求 2：多智能体协同的资源生成（5+ 类资源）

**方案**：DeepTutor 6 Agent 协同 + OpenMAIC 多模态引擎

| 资源类型 | 负责方 |
|----------|--------|
| 课程讲解文档 | DeepTutor Deep Research（RAG 生成，含引用标注） |
| 知识点思维导图 | DeepTutor Visualize 模式 |
| 练习题（选择/判断/填空/解答/变式） | DeepTutor Quiz 模式 |
| 拓展阅读材料 | DeepTutor Deep Research（RAG + 网页检索 + 论文检索） |
| 多模态视频/动画 | OpenMAIC（TTS 讲课 + 动画分镜 + PPTX 导出） |
| 代码实操案例 | DeepTutor Deep Solve 模式 |

**防幻觉机制**：CheckAgent 审核所有生成资源 + Memory Graph 每条结论追溯到证据来源 + 不确定性提示（"当前资料不足"）

**答辩话术**："6 个角色 Agent 分工协作——InvestigateAgent 分析意图、PlanAgent 规划路径、ManagerAgent 调度生成、CheckAgent 质量审核。资源生成覆盖讲义/导图/题库/阅读/视频/代码 6 种类型，超出比赛要求。CheckAgent 和 Memory Graph 双层防幻觉机制确保学术内容准确性。"

---

### 要求 3：个性化学习路径规划和资源推送

**方案**：PlanAgent + ManagerAgent 协同

- **路径规划**：基于画像 + 诊断结果，分阶段生成学习路径，明确每阶段目标/任务/时长
- **资源推送**：ManagerAgent 根据画像的认知风格偏好，精准匹配资源类型（如视觉型推送图解和视频）
- **动态调整**：GradingAgent 反馈 → ProfileAgent 更新 → PlanAgent 重规划（闭环）

---

### 要求 4：智能辅导（加分项）

**方案**：SolveAgent（DeepTutor 自带）+ OpenMAIC TTS

- **文字解答**：SolveAgent 基于 RAG 知识库 + 讯飞星火生成详细解答
- **图解说明**：DeepTutor Visualize 模式生成概念图
- **短视频讲解**：OpenMAIC TTS 讲课 + 动画分镜
- **苏格拉底追问**：配置 SolveAgent 的 prompt 为启发式追问模式

---

### 要求 5：学习效果评估（加分项）

**方案**：GradingAgent（你写）

| 评估维度 | 说明 |
|----------|------|
| 思路正确性（40%） | 解题思路是否正确 |
| 步骤完整性（30%） | 解答步骤是否完整 |
| 计算准确性（20%） | 计算过程和结果是否正确 |
| 表达规范性（10%） | 书写和表达是否规范 |

错误归类：概念错误、计算失误、审题偏差、方法不当、知识遗忘 → 每种类型自动触发对应学习建议

## 八、部署与开发计划

### 阶段一：环境搭建（1 天）

```bash
pip install deeptutor
# 配置讯飞星火
export LLM_PROVIDER=spark
export SPARK_API_KEY=xxx
export SPARK_API_SECRET=xxx
export SPARK_APP_ID=xxx
# 启动
deeptutor serve
```

### 阶段二：ProfileAgent + GradingAgent 开发（2-3 天）

按 DeepTutor Agent 规范写两个 Python 文件，注册进 Agent Loop。

### 阶段三：OpenMAIC 接入（1-2 天）

```bash
git clone https://github.com/THU-MAIC/OpenMAIC
# 配置 TTS 为讯飞开放平台
# 对接 DeepTutor ManagerAgent
```

### 阶段四：联调 + 测试（2-3 天）

准备 1 个完整演示案例（如"电子信息专业学生两周入门机器学习"），从对话→画像→路径→资源→评估走通全流程。

### 阶段五：文档 + 演示视频（2 天）

按比赛要求输出：演示 PPT、系统开发说明书、测试说明书、AI Coding 工具说明、开源协议说明。
