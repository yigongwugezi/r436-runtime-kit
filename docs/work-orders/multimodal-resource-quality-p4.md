# P4 多模态学习资源、质量审查与协同展示

## 目标

在既有讲义资源工作区上补齐可持久化的结构化学习资源、轻量质量审查、反馈驱动重生成和安全的工作流轨迹展示。

## 已确认基线

- `ResourceModel` 已保存资源类型、正文和 JSON 元数据。
- `section_generated_resources` 已生成五类文本资源，并有章节思维导图服务。
- `MultimodalAgent`、多模态注册表和前端 Mermaid 渲染组件已存在。
- P3 已提供按用户、学科和小节隔离的资源反馈事件。

## 施工边界

- 只复用现有共享 LLM Provider；不新增任何远程 AI Provider、密钥或付费服务。
- 优先使用 Mermaid、Markdown、结构化表格和本地确定性模板。
- 不改聊天路由、Planner、学习路径结构、讲义主生成、教材主链路或 DeepTutor 调用顺序。
- 外部搜索结果保持瞬态，不写入资源库。

## 验收重点

- 新资源有明确类型、可渲染正文、质量状态和安全 fallback。
- 递归调用栈可稳定产出 `factorial(4)` 的调用与返回轨迹。
- 质量与反馈只影响当前用户、学科、小节和资源类型。
- 轨迹仅记录真实执行步骤和安全摘要，不包含 prompt、密钥、完整画像或聊天记录。
