## 判卷展示：内联动画

提交后题目卡片下方无缝展开结果：

- **正确**：绿色边框 + ✓ + 解析
- **错误**：红色边框 + ✗ + 正确答案高亮 + 错误类型标签 + 建议

```
┌─ 错误 ────────────────────────────────────┐
│ ✗ 正确答案是 B                           │
│                                           │
│ 📌 错误类型：概念错误                      │
│ 极限的四则运算法则要求两个极限分别存在      │
│ 才能拆开，不能先拆再判断。                 │
│                                           │
│ 💡 建议：回顾极限运算法则的前提条件         │
└───────────────────────────────────────────┘
```

## 交互流程

```
首页卡片 → 选择练习类型 → 答题 → 提交判卷 → 查看结果
    ↑                                    │
    │        错题本 ← 错误归类 ←─────────┘
    │          │
    │    重做/看解析
    └──────────┘
```

## 实现改动

相比于现在的单文件 PracticePage，拆成：

| 文件 | 内容 |
|------|------|
| `PracticePage.tsx` | 入口页：4张卡片 + 继续上次 + 右侧统计 |
| `PracticeQuiz.tsx` | 答题区：逐题卡片 + 提交判卷 + 结果展示 |
| `PracticeWeak.tsx` | 错题本：筛选列表 + 重做/解析 |
| `PracticeHistory.tsx` | 答题历史列表 |

不需要新增页面路由——全部在 `/practice` 下通过 tab/状态切换。
